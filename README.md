## How I Build

```text
Real problem, real workaround
  -> Narrow wedge with a painful job
  -> Smallest evidence-producing build
  -> Live URL, no signup wall
  -> Measure use, correct, or kill
  -> Only then, expand scope
```

Tooling cannot manufacture demand. Products earn expansion by producing evidence.

## Engineering Standards

- "Built" means local evidence. "Deployed" means the production URL was fetched and the promised behavior verified.
- Authentication and authorization fail closed. Row level security is enabled on every Supabase table with explicit policies.
- Mobile-first UI, accessible contrast, semantic controls, and useful empty, loading, and error states.
- Motion communicates state or hierarchy. It is not decoration.
- No fake volume, fake SLA, or unsupported benchmark claims in any public surface.
- Secrets live in environment variables and secret managers, never in repositories, prompts, or logs.

## Position

Most productivity and intelligence tools are either too complex, too expensive, or locked behind enterprise sales cycles. ArkNet builds the versions that just work: open in the browser, solve the problem, done.

The portfolio is deliberately wide because the goal is not one bet. It is a repeatable system for turning a real problem into a working product fast enough to learn from it.
